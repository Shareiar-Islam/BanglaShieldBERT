# BanglaShieldBERT

**A Hybrid Transformer Framework for Distinguishing AI-Generated Real and Fake News in Bangla**

Undergraduate thesis · Department of CSE, Shahjalal University of Science and Technology

---

## What this is

Most fake-news detectors separate human-written real news from human-written fake
news, where source, vocabulary, and writing quality give away the answer. This work
removes those cues: both classes are generated by the same LLMs from the same source
articles, so they share grammar, structure, topics, and professional tone. Only the
underlying facts differ.

The question is whether subtle contextual and structural signals can still separate
two equally fluent AI-generated classes.

## Results

| Category | Best model | Accuracy |
|---|---|---|
| Machine learning | LinearSVC + CountVectorizer | 88.9% |
| Deep learning | CNN | 94.2% |
| Transformer | BanglaBERT | 94.9% |
| **Proposed** | **BanglaShieldBERT** | **98.30%** |

A 66.7% relative error reduction over the BanglaBERT baseline (5.1% → 1.7%).

## Dataset

115,028 human-written articles scraped from five Bangla newspapers, cleaned to 97,588,
and 30,000 used as source material. Llama-3.3-70B and GPT-OSS-120B generated both
classes, yielding 50,282 articles after cleaning — 25,909 AI-real and 24,373 AI-fake.
